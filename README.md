# 天天滚动 · 西综考研艾宾浩斯复习

仿制「天天滚动」微信小程序的 **H5 原型（可安装 PWA）**——西综（西医综合）考研内容 + 艾宾浩斯记忆曲线每日滚动复习。

## PWA（可安装 App）

本应用已配置为 PWA：`manifest.json` + `sw.js`（离线缓存）+ 图标（`icons/`）。部署到 **HTTPS 地址**后，手机/电脑浏览器打开 → 「添加到主屏幕」→ 桌面出现 App 图标，全屏使用、可离线。

- 图片卡图片托管于阿里云 OSS（`ttgd-images.oss-cn-hongkong.aliyuncs.com`），公网可加载
- 本地预览：`node server.js` → http://127.0.0.1:8341（localhost 也支持 Service Worker）

## 快速开始

无需安装任何依赖，直接用浏览器打开 `index.html` 即可使用（推荐 Chrome / Edge 手机模拟模式，或直接手机浏览器打开）。

```bash
# 或用内置的零依赖 Node 静态服务器
node server.js
# 然后访问 http://127.0.0.1:8341
```

> 说明：这是独立实现的 H5 原型（非原小程序代码），仅用于看效果。

## 功能

### 📅 今日（任务看板）
- **本阶段目标** + 滚动进度环：今日 X / Y 张、明日到期 Z 张
- **以题带动 · 每日记录卡**：今日 X 题、已记录 Y 天
- **三段任务**：学成选择题（进行中/等待中）、以题带动知识点复习（进行中/待解锁）、错题回炉（进行中/待解锁），点击即可直接进入对应模式
- **学习模式切换**：`全部 / 只刷题 / 只Anki`，开始学习按所选队列进
- **今日队列预览**（复习 + 新学，错题标记"重刷"）
- **各科掌握度**（按毕业/掌握占比）

### 🎯 练习中心
- **以题带动 · 每日记录** 高亮卡
- **按章节练习**（两级下钻）：先按科目（生理/生化/病理/内科/外科/诊断）分组显示「已完成 X / Y 题」与百分比，点进某科可看到它的**各章节**，再点击章节进入该章节刷题
- **整卷考试**：自选题目数与时长（默认 180 分钟），限时作答、交卷评分，生成错题回顾与考试记录
- **错题本**：汇总所有答错过的题，可一键全部重练
- **搜索、收藏与笔记**：快速定位内容，☆ 收藏，✎ 个人笔记
- **考试记录**：近若干次整卷考试的成绩与用时

### 📖 学习（双模式）
- **选择题**：作答后立即判分并显示解析；答错自动安排当天重刷
- **记忆卡（Anki 间隔重复）**：点击卡片翻面，按 **重来 / 困难 / 良好 / 简单** 四档评级，每个按钮实时预览下次复习间隔
- 完成一轮后可「再学一轮错题」

### 🗂 内容库
- 内置 22 条西综示例内容（生理、生化、病理、内科、外科、诊断），已按「科目→章节」划分
- **Anki 卡组导入**：顶部 🧠 按钮，粘贴/选择 Anki 导出的**纯文本(Notes in Plain Text)或 CSV**（勾选"包含标签"），批量导入为记忆卡；标签用作科目/章节或手动指定
- **Anki `.apkg` / `collection.anki2` 一键转换**：见下方「Anki .apkg 转换」，零依赖本地转换后再用 📚 导入
- **题库批量导入（CSV）**：顶部 📚 按钮，支持粘贴或选择 CSV 文件，一次导入整份题库（选择题 + 记忆卡），并按「章节」列自动归类
- 顶部搜索框：按题干 / 科目 / 解析 / 笔记模糊搜索
- 筛选：全部 / 选择题 / 记忆卡 / 已毕业 / ⭐收藏
- **视图切换**：平铺列表 或 按科目·章节分组（科目下再按章节整理）
- 每条内容支持 ☆ 收藏、✎ 笔记、记忆卡暂停/恢复、删除
- 手动添加时可填「章节」
- JSON 导出 / 导入（数据备份与迁移）

#### Anki 导入

从 **Anki 桌面端 › 文件 › 导出**，导出格式选「**纯文本 Notes in Plain Text**」或「**CSV**」，**勾选"包含标签"**，得到类似：

```text
Front	Back	Tags
医学问题1	答案1	生理学 血液循环
医学问题2	答案2	生理学 神经-肌肉
```

在小程序内容库点 🧠 → 粘贴或选中该文件 → 解析预览 → 导入。
- 字段按表头（front/back/tags/正面/背面/标签）或位置映射（第 0 字段=正面，第 1 字段=背面）
- **标签**：默认第 1 个标签作科目、第 2 个作章节；也可手动填固定科目/章节
- 导入为**记忆卡**（进入 app 的 Anki SM-2 间隔重复调度）

#### 图片挖空卡（Image Cloze）导入

如果你的 Anki 卡组是"**图片挖空**"（`Kevin Image Cloze+` 这类，卡面是图片 + 挖空坐标，答案藏在图里），用转换器把图片和卡片导出：

```bash
# 解出 192 张图片到 images/，并生成 image 卡数组 JSON
node tools/apkg2imgcards.js "你的卡组.apkg" 导入_图像卡.json
# 合并多套卡组（外科学/生理学/病理学/内科学）并生成首启自动导入脚本
node tools/merge_imgcard_decks.js
```

然后在内容库点 **⇪ 导入**，粘贴 `导入_图像卡.json` 的内容（一个数组）即可 —— 得到**图片挖空卡**：
- 正面：显示教材截图，挖空区域被**白色色块盖住**（答案隐藏）
- **点击空白处 → 只显示对应答案**；另有「显示全部答案」按钮
- 学习前可**按科目/章节勾选**要学习的卡片
- 需通过 `http://127.0.0.1:8341` 打开（图片在 `images/` 里由本地服务器提供）

当前内置 **4 科共 1065 张**：外科学 192、生理学 335、病理学 163、内科学 375。

#### Anki `.apkg` / `collection.anki2` 转换

如果你只有 `.apkg`（Anki 卡组包）或 `collection.anki2`，用内置的零依赖转换器（自带 `node:sqlite`，无需联网）：

```bash
# 把 .apkg 转成小程序 CSV（输出到 导入的Anki.txt）
node tools/apkg2csv.js "你的卡组.apkg" 导入的Anki.txt
# 或直接传裸的 collection.anki2
node tools/apkg2csv.js collection.anki2 导入的Anki.txt
```

然后在内容库点 📚（CSV 导入）粘贴/选择生成的 `导入的Anki.txt` 即可。

- 自动识别 zip (.apkg) / 裸 SQLite；读取 `notes`/`cards`/`col` 里的 decks、models、tags
- 默认字段映射：正面 = 字段0（或 front/正面/题干…），背面 = 字段1
- 科目/章节：取自卡组名（`生理学::血液循环` → 科目=生理学、章节=血液循环），没有则用标签
- 输出为标准 CSV（`type,subject,chapter,question,...,explain`），可直接被 📚 导入

#### CSV 题库格式

带表头（推荐，含可选的 `chapter` 章节列）：

```csv
type,subject,chapter,question,optionA,optionB,optionC,optionD,answer,explain
quiz,生理学,血液循环,心输出量约为?,3 L/min,4.5~6 L/min,8~10 L/min,12 L/min,B,正常成人安静时心输出量约 4.5~6 L/min。
card,生理学,神经-肌肉,神经-骨骼肌接头兴奋传递的递质?,,,,,,乙酰胆碱（ACh）。
```

- `type`：`quiz`（选择题）或 `card`（记忆卡）
- `chapter`（章节）：可选。填了就会按「科目→章节」自动分组，空则归入「未分章」
- 记忆卡只需保留 `type,subject,chapter,question,explain`（选项列留空）
- `answer`：答案选项字母 `A-D` 或序号 `1-4`
- 无表头时按 `subject,question,optionA,optionB,optionC,optionD,answer,explain`（全部当作选择题）
- 含逗号的字段用英文双引号包裹，如 `"问,含逗号?"`；文件需为 UTF-8（可含 BOM）

## 调度规则（双轨）

**选择题 · 艾宾浩斯**
- 新学条目第 0 阶段，学习当天记为"新学"，**次日**进入第一次复习
- 复习间隔默认 `1、2、4、7、15、30` 天（可在设置中自定义）
- **答对** → 阶段 +1，按间隔推进；**答错** → 阶段回退一级，**当天重刷**
- 完成全部阶段 → 毕业（不再进入复习队列）

**记忆卡 · Anki SM-2 风格**
- 状态机：`new → learning → review`，复习遗忘 → `relearning`
- 学习步骤默认 `1、10 分钟`（可配置），完成后毕业进复习
- 四档评级：
  - **重来**：回到学习步骤第一步，ease -0.2（下限 1.3），计入遗忘次数
  - **困难**：间隔 × 1.2（至少比原间隔多 1 天），ease 不变
  - **良好**：间隔 × ease（默认 2.5），ease 不变
  - **简单**：间隔 × ease × 1.3 加成，ease +0.15（上限 3.0）
- **按日历天到期**：复习间隔取整到天、到期时间对齐目标日当地 0 点——当天到期的卡片，早上打开 App 就在今日队列里，不用等到前次复习的具体时刻
- **间隔抖动（fuzz）**：≥2.5 天的复习间隔自动 ±8%（±1~4 天）随机打散，避免同一天学的卡片永远挤在同一天到期；评级按钮预览显示未抖动的基准间隔
- 每次评级按钮都实时显示将安排的间隔（分钟/天/月/年）
- 「明日到期」统计同时包含选择题与 review 态记忆卡

## 数据存储

所有数据保存在浏览器 **localStorage**，键名 `ttgd.*`。导出 JSON 可完整备份内容、设置、学习记录与考试记录；导入会替换现有全部内容。
